# terminal-pet
Rust (crossterm + ratatui + rand 0.9). Shared engine: `src/app.rs` state machine, `src/art.rs` Canvas + squid drawing, `src/social.rs`/`src/link.rs` visits. Non-squid pets implement the `Pet` trait in `src/pet.rs` (engine code never matches `Kind::Cat`/`Kind::Dog`; the squid stays off the trait). Per-pet: `src/cat.rs` (child module of app; breeds, cat poses/timers), `src/cat_art.rs` (cat + room drawing), `src/dog.rs` (breeds, poses, timers, `Pet` impl), `src/dog_art.rs` (dog + backyard). To add a pet follow the wiki checklist `Adding-a-pet.md`. Session stats (age, fed/petted/booped, ruffle/drag seconds; memory only) live in `src/stats.rs`; the footer and the `i` card are drawn by `art::frame()` on top of `render()` so the squid golden hash is untouched; per-pet drag words come from `Pet::drag_label`/`drag_verb` (squid hard-coded). Visit layout uses `Pet::stage`/`visit_scale` (the dog's whole pane is the lawn during a visit; guests may stand in front of the props, about 3/4 of the dog's height; the seated dog is about 70-81% of the pane height, never shorter than the cat, and is drawn over the props). `src/lib.rs` has `cli()`; bin `terminal-pet` (`--pet`, squid by default). The squid must stay byte-identical (golden test): never touch the squid rng stream from cat or dog code.
The dog sits by default (`draw_sit`, front view) and stands (side-view `Rig`) only for actions; see `DogPose::seated`. Rust is installed via rustup in ~/.cargo (`. ~/.cargo/env`). Check: `cargo test && cargo clippy --all-targets -- -D warnings && cargo fmt --check`.
Try it headlessly: `tmux -L x new-session -d -x 120 -y 40 ./target/release/terminal-pet --pet cat`, then `capture-pane -p`.
Docs live in the GitHub wiki, cloned into gitignored `wiki/` (its own repo: commit and push from inside it, branch `master`; images are in `wiki/images/`). `scripts/ansi2png.py` renders `tmux capture-pane -e -p` to PNG. To test two pets together use a short `XDG_RUNTIME_DIR` (socket paths max ~100 chars). Cats send `Msg::Mouse`, squids send `Msg::Ink`, dogs send `Msg::Bark`; a guest in your tank is reacted to locally (`Guest.startle/splat`) since away pets ignore messages.
